# LLM 系统设计：实践指南

> 这是 [book/](../book/) 的中文版。译文和英文原版同步维护，发现问题请提 issue。

这个目录是本项目 LLM 部分的书籍版：内容和主题讲解（topic walkthroughs）里那套生产级
LLM 系统设计材料是同一份，但改写成了以教学为先的章节。仓库顶层是按面试练习来组织的，
这些章节则是一条可以从头读到尾的教学线。

每一章是一个目录，一节一个文件。开头用一段候选人和面试官的对话把问题范围圈定下来，
然后把设计从头到尾走一遍，借鉴真实团队在生产环境里的做法（附一手来源链接），最后以
面试问答和自测收尾。图表是实际跑出来的 matplotlib 图和 mermaid 图，再加上来自
Neurarch 模型库的**经过验证的参考架构**，可以按真实维度在线打开，而不是截图。

## 学完能做什么

- 弄清一个模型是怎么诞生的：生命周期、数据整理与预训练、继续预训练，以及用 LoRA、SFT、DPO 和 RLHF 做后训练。
- 算清 LLM 服务的真实成本：KV cache、连续批处理、投机解码、成本优化和流式输出。
- 把模型做小，同时不假装这是免费的：量化、剪枝、蒸馏，以及压缩后的模型必须通过的验收测试。
- 让模型有知识可依：RAG、语义搜索，以及 embedding 和重排这一套。
- 把模型组合成产品：agent 编排和多模态服务。
- 知道系统确实在工作，并让它持续工作：离线和在线评估、带误差棒和污染控制的模型 benchmark、安全与护栏、生产环境监控。
- 望向前沿：世界模型和世界动作模型（world-action model），让具身智能体能做规划，并在仿真和真实机器人上评估。
- 把每一个设计决策和它底下的架构连起来，在真实的计算图上追溯，而不是画几个方框。

## 技术要求

只需要一个现代浏览器，就能打开全书用作图表的那些经过验证的参考计算图。每张图都链接到
[Neurarch 模型库](https://github.com/neurarch-ai/awesome-llm-model-zoo)，架构会以真实维度
在编辑器里在线打开。各章会点名用到的配套工具（近似最近邻索引、重排器、推理服务器、
特征或 trace 存储），但阅读本身不要求安装任何东西。

每章 capstone 的结尾都有一个只依赖 Python 标准库的可运行程序。想跑的话，任何 Python 3
都行，不需要别的，也没有哪一章要求安装框架。

## 怎么用这本书

打开一章的目录，按顺序读各节（从该目录的 README 开始）。每章以面试问答和自测收尾，并
链接一组一手的生产工程文章。读完一章，打开它的图，试着回答问题，再顺着延伸阅读去看
真实团队是怎么把同一个系统做出来的。

每一章最后都有一个 capstone（"把它们拼起来：完整的方案"），把本章的技术组装成一个
完整、算过账的方案：一套适合第一个系统的默认技术栈（带明确取向）、把本章场景从头到尾
搭一遍并做好容量和费用估算、同一条管线在两组截然不同的约束下重新推导，以及一个经过
测试、零依赖、可运行的参考实现（单文件 RAG、连续批处理模拟器、paged KV 分配器、CEM
规划器等等）。如果一章读起来像一份选项菜单，capstone 就是"在我的约束下到底该选哪些"的
参考答案。由 [Neurarch](https://www.neurarch.com) 出品。
