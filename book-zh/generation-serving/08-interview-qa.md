# 8. 面试问答

## 常考的

**问：** 生成一张图，钱到底花在哪？

答：花在去噪器的前向评估次数上。这个数是 $N_{\text{FE}} = S \cdot c$，$S$ 是采样器步数，开了 classifier-free guidance 时 $c = 2$，因为 guidance 要把网络跑两次，一次有条件、一次无条件。链路里其他部分（文本编码、VAE 解码、安全分类）每请求只付一次。只报步数不说 guidance 开没开，等于只报了一半成本。

**问：** 你们的产品出四个变体。这比出一张贵多少？

答：几乎不贵。四个变体是同一个去噪循环的 batch 维度，共用同样的 $N_{\text{FE}}$ 次前向，只是张量更大。这正是产品要出一格图的原因，而把一格图按四个请求计价，会算错将近四倍。

**问：** 怎么从 30 步做到 4 步？

答：两个阶段。先换采样器，这是免费的，能把训练时的步数降到大约 20 到 30 次评估，权重一点不动。再往下就得蒸馏：consistency 蒸馏、它的 latent 和 LoRA 形态，或者用对抗式蒸馏做到 1 到 4 步。第二个阶段永远要付多样性。

**问：** 为什么 2048px 不止是 1024px 的四倍？

答：因为 latent 是平方增长的，注意力对 token 数又是平方。1024px 在下采样 8、patch 2 下是 4096 个 token；2048px 是 16384。token 四倍，注意力工作量十六倍。

**问：** 显存花到哪去了？

答：VAE 解码，不是去噪循环。它的激活显存随输出像素增长，所以 OOM 只在高分辨率、而且只在请求末尾出现。分块解码能把它框住。

## 有坑的（能分出高下的追问）

**问：** p95 是十二秒，你的成本模型说下限是三秒。差距在哪？

答：不在去噪器。先看排队（到达率对容量，以及有没有准入控制），流量尖峰的话再看冷启动，然后看循环周边的链路：没缓存的文本编码、每隔几步做的全分辨率预览、串在全分辨率解码之后的安全那一遍。先建成本模型的价值恰恰在于把这件事变成一个短清单。

**问：** 你们上了编译引擎，然后部署变痛苦了。发生了什么？

答：编译把形状冻住了，于是每种分辨率和 batch 都是自己的引擎，每个引擎都是要跟模型一起版本化的构建产物。而且冷启动从大约十秒变成一分钟左右，缩到零就不成立了。通常的解法是：平稳流量用编译池，再加一个热的 eager 副本接住空闲后的第一个请求。

**问：** 用户说新模型"生成的东西都长一个样"。你们上了什么？

答：一个蒸馏模型。步数蒸馏会让输出分布变窄，表现为同一个 prompt 在不同种子下的多样性下降，而不是单张图变差。它也不会在演示 prompt 上出现。修法是路由：草稿一格图用蒸馏模型，定稿渲染用完整模型。

**问：** guidance 既然让成本翻倍，为什么不干脆关掉？

答：因为 guidance 正是让图跟着 prompt 走的东西，关掉会改变用户拿到的结果，那是一个伪装成优化的产品改动。等价而不改产品的做法是 guidance 蒸馏，把这个效果训进单次评估里。

**问：** 这里的改动怎么评估？

答：在固定 prompt 集上做配对人工偏好测试，再加一个自动的 prompt 贴合度代理指标（用一个 VQA 模型问要求的内容在不在，或者图文相似度分数），在两轮人工之间便宜地抓回退。同时保住带种子的确定性，好让两个版本能在完全相同的输入上做对比。

## 常被答错的（陷阱）

**问：** 你会怎么把它做快？大多数候选人从量化和批处理开始。

**诱人的答案：** 量化权重、多攒批、加机器。

**为什么不对：** 那是给显存带宽受限的自回归解码器准备的杠杆。这个负载是算力受限、形状固定、没有 KV cache，而主导项是一个你可以直接攻击的乘数。评估次数砍一半，成本就砍一半；跟它比，量化是二阶效应。

**该怎么说：** 先点名成本单位，砍评估次数（采样器、guidance 蒸馏、步数蒸馏），再用编译引擎让每次评估更便宜，然后才谈把一格图放进一个 batch。

---

**问：** 用 FID 检查质量有没有回退，行吗？

**诱人的答案：** 行，那是图像生成的标准指标。

**为什么不对：** FID 衡量的是相对某个参考数据集的两个图像分布之间的距离。它说不出某一个特定 prompt 有没有生成一张好图，对实现细节和样本数都敏感，而且一个蒸馏模型可以在 FID 不动的情况下，恰好丢掉 FID 本应检测的那种多样性。

**该怎么说：** 用固定 prompt 集上的配对人工偏好作为门，用 prompt 贴合度代理做便宜的持续检查，如果上了蒸馏模型，再加一个跨种子的多样性度量。

---

**问：** 视频不就是一堆图循环出来的吗？

**诱人的答案：** 一帧一帧生成，然后拼起来。

**为什么不对：** 各帧独立就会闪。纹理游动、身份漂移、光照跳变，因为没有任何东西把帧绑在一起。修它意味着跨时间做注意力，而这正是成本随片长超线性的原因，也是任何超过原生窗口的长度都要靠带重叠的分块生成的原因。

**该怎么说：** 把时间注意力作为要求，把带条件的分块作为实践做法，把带进度通道的队列作业作为服务形态，把每秒输出成本作为指标。
