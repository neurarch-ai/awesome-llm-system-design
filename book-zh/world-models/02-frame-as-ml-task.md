# 2. 搭成 ML 任务

所有世界模型学的都是同一个东西：一个转移函数，把状态和动作映射到下一个状态
（往往还带一个奖励或者下一个观测）：

$$\hat{s}_{t+1} = f_\theta(s_t, a_t)$$

不同之处在于 $s$ 住在哪个空间里，以及怎么监督 $f_\theta$。四种范式占主导，
把它们一一点名，就是搭骨架的第一步。

## 四种范式

**生成式 / 视频世界模型。** 直接预测未来的*观测*（画面帧），以一帧参考帧为条件，
通常还带一个动作或一条语言指令。状态是一个视觉 token 网格；模型是一个大 transformer
或者扩散模型。例子：DeepMind 的 Genie（可用动作控制的生成世界，arXiv:2402.15391）、
Wayve 面向驾驶的 GAIA-1（arXiv:2309.17080）、OpenAI 把 Sora 这类视频生成器定位为世界模拟器
（2024），以及 NVIDIA Cosmos 世界基础模型。长处：照片级真实、通用、非常适合生成合成数据。
短处：贵，而且视觉保真度不保证对控制有用。

**隐空间动力学（基于模型的 RL）世界模型。** 学一个紧凑的循环隐状态及其转移，
然后完全在隐空间模型内部"想象" rollout 来训练策略。这条经典路线是 Ha 和 Schmidhuber 的
World Models（arXiv:1803.10122）、Dreamer（DreamerV3，arXiv:2301.04104），以及 MuZero，
后者只对规划所需的那些量建模（arXiv:1911.08265）。长处：样本效率高的控制，rollout 便宜。
短处：隐变量是抽象的，跨本体迁移不那么直接。

**JEPA 式预测世界模型。** 在*表征*空间而不是像素空间里做预测：先把观测编码，
再预测未来的 embedding，省掉重建每一个像素的开销和干扰。这就是联合嵌入预测架构
（joint-embedding predictive architecture）这条线（LeCun 2022 年的立场论文），
Meta 的 V-JEPA 2（arXiv:2506.09985）把它落到了视频和机器人上，其动作条件化版本用
模型预测控制来做规划。长处：高效，能从被动视频自监督地学，实验上对规划很有效。
短处：没有人能看懂的预测图像可供检查。

**VLA / 世界动作模型。** 视觉语言动作模型把观测加语言目标直接映射成动作，
有时内部带一个世界模型，有时不带。例子：OpenVLA（arXiv:2406.09246）、Physical Intelligence
的 pi-0，以及 NVIDIA Isaac GR00T。"世界动作模型"这个说法指的是把一个预训练的世界模型
（负责想象）和一个微调过的动作头（负责执行）耦合在一起。长处：端到端，可以直接部署。
短处：没有显式预测模型的话，它更多是在反应，而不是在规划。

## 对比：世界模型与 VLA 策略

这两者常被混为一谈，因为从外面看都是"一个让机器人动起来的大预训练模型"，
吃的观测一样，也都依赖大规模视频预训练。但动作产生的机制正好相反：
一个先预测若干个未来，再比较它们来挑动作；另一个从观测直接映射到动作，从头到尾没算过任何未来。

| 维度 | 世界模型（先预测，再规划） | VLA 策略（直接映射） |
|---|---|---|
| 运行时输入 | 当前观测（规划器还要一个目标） | 一样：当前观测加一个目标，通常是语言 |
| 预训练的数据 | 大规模被动视频，然后做动作条件化适配 | 大规模视觉语言语料加遥操作演示 |
| 网络输出什么 | 预测的下一状态（像素、隐变量或 embedding） | 直接输出动作 |
| 动作从哪来 | 规划器按想象出的结果给候选动作打分 | 前向传播本身就是决策；不存在候选未来 |
| 遇到训练数据之外的情况 | 仍能通过模拟后果来评估新动作 | 只能从演示过的行为插值；没见过的动作无从打分 |
| 每个控制步的运行时开销 | 模型 rollout 次数乘以候选动作数，延迟随规划投入增长 | 一次前向传播，固定且快 |
| 失效模式 | 模型误差被规划器钻空子（只在想象里可行的计划） | 分布漂移：在演示没覆盖的状态里自信地出动作 |

当部署要求严格的延迟（固定的一次前向传播塞得进控制循环，规划循环未必能）
或者要求泛化到演示集之外（想象可以给没人演示过的动作排序）时，这个差别就会改变设计；
生产上把预训练世界模型和 VLA 式动作头耦合起来的趋势，正是为了两头都要。

## 什么时候用哪一种

| 选它 | 当 | 而不是 |
|---|---|---|
| 生成式视频世界模型 | 需要合成训练数据、驾驶/场景仿真，或者一个人能看懂的预测未来 | 隐空间动力学模型，当只需要控制、像素纯属浪费算力时 |
| 隐空间动力学世界模型 | 在固定本体上做样本高效的控制；用便宜的想象 rollout 来学策略 | 视频世界模型，当照片级真实感对任务无关紧要时 |
| JEPA 预测式世界模型 | 从大规模被动视频自监督预训练，然后在机器人上零样本规划 | 重建像素的模型，当重建开销对控制毫无帮助时 |
| VLA / 世界动作模型 | 想要一个跟随语言目标、现在就能上硬件的端到端策略 | 纯预测器，当交付物是动作而不是预报时 |

**工具。** 隐空间动力学：DreamerV3 参考实现，以及 MuZero 的开源复现
（muzero-general、EfficientZero）。仿真加 RL 的管线：Gymnasium、Stable-Baselines3、
DeepMind 的 dm_control，以及做 GPU 并行机器人仿真的 NVIDIA Isaac Lab。
生成式世界模型：NVIDIA Cosmos（开放的世界基础模型加 tokenizer）。VLA：OpenVLA 的发布版和
NVIDIA Isaac GR00T。视频编码器复用多模态那一套（CLIP（OpenAI）、SigLIP（Google），
以及 Meta 的 V-JEPA 2 权重）。

**出处。** 四种范式各有各的谱系。隐空间动力学这一行从 World Models（Ha 和 Schmidhuber，2018）
一路到 Dreamer/DreamerV3（DeepMind）和 MuZero（DeepMind）；JEPA 预测式这一行是 V-JEPA 2
（Meta，2025）；生成式视频这一行包括 NVIDIA Cosmos、Genie（DeepMind，2024）和 GAIA-1
（Wayve，2023）；VLA 这一行是 OpenVLA（2024）和 NVIDIA Isaac GR00T。
架在它们之上的运行时规划用的是模型预测控制（经典控制理论）。

**实例。** 一个操作团队想让机器人在一个从没训练过的仓库里听从口头指令，
手上只有一小份遥操作数据集。因为带动作标注的数据稀缺，目标又是零样本迁移，
他们在大规模被动视频上预训练一个 JEPA 预测式世界模型（广泛地学习物理动力学），
再加一个用那点机器人数据训练的动作条件化头，运行时用模型预测控制做规划。
他们的工具箱里还留着一个生成式视频世界模型，用途不同：生成合成的仓库场景来扩大覆盖面。
最终系统按真机成功率评估，而不是看两个模型预测的画面有多逼真。
